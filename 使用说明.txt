屏幕准星

双击 ScreenCrosshair.exe，准星会显示在主屏正中央。
无需安装或管理员权限。默认绿色十字、黑色描边，背景透明，鼠标点击穿透。

快捷键（所有快捷键都需要同时按住 Ctrl 和 Alt）：
Ctrl + Alt + F8   显示 / 隐藏
Ctrl + Alt + F9   打开设置
Ctrl + Alt + F10  切换显示器
Ctrl + Alt + F11  完全退出

也可以双击任务栏通知区域的准星图标打开设置，右击可显示、隐藏或退出。
如果图标收在通知区域的上箭头菜单里，请展开查看。
再次双击程序会打开已有程序的设置，不会重复叠加准星。

设置包括十字 / 圆点 / 圆环 / 霰弹枪 / 狙击枪 / 三叉（奔驰）/ X 形样式。
选择“自定义组合”后，可以分别开关四条直线、四条斜线、圆环和中心点。
先选择三叉（奔驰）或 X 形，再切自定义，可继续编辑其部件并保留原来的斜线角度。
三叉加圆环、中心间隔设为 0，即可组合出相连的三叉圆环。
所有部件都关闭时准星完全透明；开关状态可以随自定义预设一起保存、套用或删除。
深色设置界面配有统一标题栏、边框与托盘图标。
颜色可用调色板或 #RRGGBB 自定义，长度、间隔和粗细支持滑块及数字输入。
可输入小数，最多保存两位；滑块和输入框上下键以 0.1 px 微调。
范围：长度/半径 2–32 px，间隔 0–20 px，粗细 0.1–8 px。
设置顶部“正在调整”选择普通（十字）、霰弹枪、狙击枪，三套分别保存。
样式、颜色、尺寸、描边和中心点都可独立调整；左侧显示当前所选配置预览。
“重置当前”只重置所选配置。编辑对象不会强制切换游戏里的准星。
三类各有独立预设列表。在对应的“普通预设 / 霰弹枪预设 / 狙击枪预设”旁点击“保存…”并命名。
当前类别已有同名预设时点击“更新”替换；不同类别可以同名，选择预设并“套用”只修改当前类别。
点击“删除”并确认移除当前类别的预设，其他类别及已套用外观保留。预设在重启后保留。
“同步通用参数”把当前正在调整类别的长度/半径、间隔、粗细、颜色和描边一次复制到另外两类。
各类形状、中心点、线条/圆环开关和斜线角度保留，已保存的预设保留，之后仍可各自调整。
v1.3.2 升级时把旧版共享预设各复制一份到三个列表，此后独立管理。
升级保留三类配置、识别开关、已框选区域与检测间隔。先退出旧版再启动新版。
修改即时生效，自动保存到 %LOCALAPPDATA%\ScreenCrosshair\settings.xml。
关闭设置窗口后准星继续显示；请用退出快捷键或托盘“退出”结束程序。
没有设置开机启动。

Apex 自动识别（实验性）：
1. 在训练场拿起一把武器。
2. Ctrl+Alt+F9 打开设置，选择简体中文或 English。
3. 点击“框选两个枪名…”，20 秒内切回 Apex，拖动框住两个武器名称。
   亮的和暗的都包含，尽量避开上方枪械图标、弹药数字和拾取提示。Esc 取消。
4. 框选完成后自动启用。关闭设置、切回 Apex 开始识别。

只让文字明显更亮的枪名决定准星；两个名字都暗或亮度接近时暂不确认。
识别后使用对应的整套配置。默认霰弹枪为圆环加点，狙击枪无下方竖线。
G7、30-30、波塞克和三重式（神射手）也使用狙击枪配置。
从 v1.1.0 更新后必须重新框选两个枪名，其他外观和间隔设置保留。
默认 1 秒检测一次，可选 0.5 / 1 / 2 秒；连续两次一致才切换，三次未知恢复普通样式。
图片仅在内存中处理，不保存、不上传；只读选定小区域，切出 Apex 会暂停。
HUD 位置或缩放变化后请重新框选。需要 Windows 对应语言的 OCR 组件。
切到设置/聊天等窗口时暂停，切回 Apex 自动继续；外观调整不会重置识别。
“未读到枪名”表示该次没有可靠结果，不等同于已暂停检测。
“状态记录”可查看最近 30 次状态变化、时间、最近检测结果与 OCR 文字。
记录仅在内存中保留，退出清空，不新增截图或日志文件。
真实游戏准确率和帧率影响尚待验证；EA 没有明确认可此工具，不能保证不会封号。

适用于 Windows 10 / 11 桌面、窗口化或无边框窗口。
独占全屏可能无法显示，遇到这种情况请改用无边框窗口。
没有针对具体游戏做兼容性验证。

源码位于 source。重建：用 PowerShell 运行 source\build.ps1。
